# Высадка UH-60 по тросу

Автор **JozinZBazin**, версия **0.1.0**, целевая сборка **SPT 4.1.6**, Windows, офлайн.

**Экспериментальный кандидат 0.1.0: не подтверждён как стабильный игровой релиз.**
Публичный пакет проверен только вне игры; проверка в рейде на чистой SPT не проводилась.
Ранее были сильные просадки FPS при
существовании вертолёта; устранение всей проблемы пока не доказано.

Выбор перед рейдом: обычное появление или подлёт UH-60, ожидание в салоне,
выпуск тросов, поочерёдный спуск, возврат управления, уборка тросов и отлёт.
Поддерживается игрок и до четырёх распознанных напарников PIT. Это самостоятельный
мод, но он использует отдельно установленные зависимости, а не включает их в себя.

## Зависимости

Обязательны полные **Icebreaker Backport 1.1.3** и **Tactical Service Control 1.3.13**,
вместе с их зависимостями. Ресурсы читаются из вашей установки, не скачиваются и
не распространяются в нашем архиве. [Таблица и ссылки](DEPENDENCIES.md).

Рекомендуются **Infil 2.1.0 + Dynamic Maps 1.2.1** для карты выбора LZ. Без них
остаётся исходная точка. **PIT Fireteam** нужен только для высадки ботов-напарников;
без него — одиночная сцена. Локальный адаптер создавался для PIT 0.10.3;
совместимость с текущим публичным 1.1.1 ещё не подтверждена. BDA не требуется.
Fika, headless и синхронизация нескольких настоящих игроков не поддерживаются.

## Установка

1. Закрыть игру, сервер и лаунчер, сохранить резервные копии профиля и настроек.
2. Отдельно установить полные обязательные зависимости по инструкциям авторов.
3. Убрать старую/приватную версию UH60 из `BepInEx/plugins` в резервную копию
   вне каталога плагинов. Вместе две реализации не запускать. Локальный адаптер
   подкреплений BDA, проверяющий старый точный хэш, эту публичную сборку не принимает.
4. Распаковать ZIP в корень SPT. Должен появиться каталог
   `BepInEx/plugins/UH60FastRopeInsertion` с двумя DLL и `assets/cabin-flight.csv`.
5. На экране локации выбрать высадку с вертолёта; с Infil/Maps выбрать LZ.
   Проверка препятствий может отклонить небезопасное место. Не все карты
   поддерживаются: Завод и Лаборатория исключены.

Личные конфиги и пути автора не включены. Новые настройки создаются автоматически.
Окно статуса по умолчанию отключено. F12 работает при наличии Configuration Manager;
без него можно редактировать созданный cfg при закрытой игре.

## Управление и диагностика

Мышь — ограниченный осмотр в салоне. Ctrl+F9 — повтор сцены в рейде.
F8 — осмотровая камера; мышь, WASD/QE, Shift; F8 — обратно к бойцу.
Ctrl+F6 — перечитать CSV; Ctrl+F7 — сохранить текущие позы.
Настройки F12: JozinZBazin-UH60FastRopeInsertion и JozinZBazin-UH60Performance.
Hide aircraft for comparison — временный диагностический тест, по умолчанию OFF.

При ошибке нужен короткий ролик и `BepInEx/LogOutput.log`; перед отправкой
проверить лог на личные данные. Для FPS оставить ещё 10 секунд после исчезновения
вертолёта. Сборка и числовые тесты не подтверждают внешний вид и плавность в игре.

Удаление: закрыть игру/сервер/лаунчер, вынести только каталог нашего мода из plugins;
при необходимости удалить два cfg `com.jozinzbazin.uh60*.cfg`. Профили не трогать.
Зависимости могут сами менять профиль — их удалять только по инструкциям авторов.
