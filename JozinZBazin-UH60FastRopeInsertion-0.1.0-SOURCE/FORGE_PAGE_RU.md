## Краткое описание

Высадка UH-60 по тросам: подлёт, салон, поочерёдный спуск отряда,
возврат управления и отлёт. С дополнительной картой выбора зоны высадки.

## Описание

Самостоятельный клиентский мод: перед рейдом можно выбрать обычное появление
или высадку с UH-60. Сцена включает подлёт, ожидание в салоне, выпуск тросов,
спуск бойцов, возвращение управления игроку и уборку тросов перед отлётом.
Размер представляемого отряда — игрок и до четырёх распознанных напарников PIT.

Полёт использует ресурсы Tactical Services; внешний вид вертолёта и троса,
крепление и исходные референсные движения читаются из Icebreaker. Они не входят
в наш архив и не становятся частью лицензии MIT. Не является портом полной катсцены.

### Установка и удаление

1. Закрыть игру, сервер и лаунчер, сохранить копии профиля и настроек.
2. Установить обязательные зависимости по инструкциям их авторов.
3. Старый UH60 вынести в бэкап ВНЕ `BepInEx/plugins`; две версии вместе не запускать.
4. Распаковать **установочный ZIP** в корень SPT с сохранением `BepInEx/plugins/`.
5. На экране локации выбрать вертолётную высадку. При наличии Infil/Maps выбрать LZ.

Удаление: при закрытой игре вынести `BepInEx/plugins/UH60FastRopeInsertion` из plugins;
по желанию удалить два cfg `com.jozinzbazin.uh60*.cfg`. Профили не удалять.
Зависимости могут менять профиль: следовать ИХ инструкциям по удалению.

### Управление

Мышь — осмотр в салоне. Ctrl+F9 — повтор сцены в поддерживаемом рейде.
F8 — осмотровая камера; мышь/WASD/QE/Shift, повторное F8 возвращает к бойцу.
F12 — параметры при наличии Configuration Manager; иначе менять cfg при закрытой игре.

### Известные ограничения

Публичный пакет проверен вне игры, без нового рейдового теста. Нельзя обещать
устранение прежней сильной просадки FPS, идеальное освещение, совместимость с
новым PIT или корректность каждой площадки. Проверка препятствий может отменить
небезопасную высадку. Сетевой режим/Fika/headless не реализованы.
Приватный BDA-адаптер с проверкой старого хэша DLL эту сборку не принимает.
Для сообщения об ошибке: короткое видео и `BepInEx/LogOutput.log` без личных данных.
